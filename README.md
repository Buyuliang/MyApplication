# MP4 to MP3 Converter

一个简单、高效的 MP4 转 MP3 音频提取工具，帮助你快速从视频中提取高质量音频文件。

---

## ✨ 功能特性

* 🎬 支持 MP4 视频转换为 MP3 音频
* 🎵 高质量音频输出
* ⚡ 快速稳定的转换速度
* 🧩 简洁直观的用户界面
* 📁 支持本地文件选择与导出
* 🔁 批量转换（如支持可保留）

---

## 📦 安装

### 方法一：下载安装包

1. 下载最新 Release 版本
2. 安装并打开应用
3. 选择 MP4 文件开始转换

### 方法二：从源码构建

```bash
git clone <your-repo-url>
cd <project-folder>
# 根据你的项目填写构建方式
```

---

## 🚀 使用方法

1. 打开应用
2. 选择需要转换的 MP4 文件
3. 设置输出路径（如可选）
4. 点击「转换」
5. 等待处理完成并保存 MP3 文件

---

## 📁 输出说明

* 默认输出格式：MP3
* 音频质量：高质量编码（具体码率视设置或实现而定）
* 输出位置：用户指定目录或默认目录
